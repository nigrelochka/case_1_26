# Text Analyzer

Text Analyzer — сервис для анализа текста.

## Возможности

Проект умеет:

- определять язык текста;
- анализировать тональность текста;
- считать статистику текста;
- определять лексическое разнообразие;
- оценивать читаемость текста;
- анализировать несколько текстов одновременно;
- сохранять результаты анализа в Redis;
- возвращать результат через FastAPI.

## Используемые технологии

- Python
- FastAPI
- Redis
- Docker
- Pytest
- GitHub Actions

## Запуск проекта

Самый простой способ запустить проект — через Docker.

```bash
docker compose up --build
```

После запуска API будет доступен по адресу:

```text
http://127.0.0.1:8000
```

Swagger-документация:

```text
http://127.0.0.1:8000/docs
```

## Основные эндпоинты

### Проверка работы приложения

```text
GET /health
```

### Анализ одного текста

```text
POST /analyze
```

Пример запроса:

```json
{
  "text": "Сегодня хороший день. Я проверяю работу анализатора текста."
}
```

### Анализ нескольких текстов

```text
POST /analyze-batch
```

Используется для анализа нескольких текстов за один запрос.

## Redis

Redis используется для кэширования результатов анализа.

Если один и тот же текст анализируется повторно, приложение может вернуть уже сохранённый результат из кэша.

## Тесты

Для запуска тестов используется Pytest.

```bash
python -m pytest
```

Если всё работает правильно, тесты должны пройти без ошибок.

## CI

В проекте настроен CI через GitHub Actions.

При push в ветку `develop` GitHub автоматически:

1. устанавливает Python;
2. устанавливает зависимости;
3. запускает Redis;
4. запускает приложение;
5. запускает тесты.

Если тесты проходят успешно, GitHub Actions показывает статус `Success`.

## Структура проекта

```text
application/       — основная логика приложения
domain/            — основные типы и интерфейсы
infrastructure/    — Redis и функции анализа
interfaces/        — FastAPI и схемы
tests/             — тесты
web/               — web-интерфейс
main.py            — точка запуска приложения
config.py          — настройки проекта
Dockerfile         — сборка Docker-образа
docker-compose.yml — запуск приложения и Redis
requirements.txt   — зависимости проекта
```
